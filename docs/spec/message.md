## 1. Hozzáférés a szimulátorhoz

A feladathoz saját token és MCP-végpont tartozik — ezt külön üzenetben küldöm. Amíg ez nincs meg, csak a starter pack alapján tudsz építkezni (a LOOP_CONTRACT_TEMPLATE.md és a minta-forgalom alapján);
dev kört futtatni és vizsgát indítani nem. Ha bármikor elakadsz, vagy a token nem működik, írj azonnal — nem csak az első napon.

## 2. Feltételek — mivel díjazás nélkül vállaltad

Fontos, hogy ez tisztán legyen kimondva:

```
Jogátruházás nincs: amit írsz, a tiéd marad.
A beadott anyagot — a kódot, a Claude Code session-átiratokat és a worklogot — átnézem és
értékelem ; éles rendszerbe nem kerül.
Az anyagot kizárólag én nézem át, értékelési céllal, és az értékelés lezárása után 6 hónappal töröljük.
A titoktartás kölcsönösen él: a kiírás, a szimulátor és a beadott anyag köztünk marad. A szimulátor
tartalma szintetikus.
Bármikor abbahagyhatod, következmény nélkül.
A visszajelzést mindenképpen megkapod, akár befejezed, akár nem.
```

## 3. Időzítés

Jelezted, hogy jövő hét elején végeznél. Kérlek:

```
erősítsd meg, melyik napra tervezed a beadást;
a vizsgakört (start_exam) előre jelezd — nagyjából 24 órával korábban írd meg, mikor indítanád.
A vizsga egy próbálkozás, és amíg fut, nem nyúlunk a szerverhez (nincs újraindítás, nincs telepítés).
Ehhez tudnom kell az időpontot.
```

**Amit a beadásnál várok** (a kiírás szerint): a loop-szerződés (cél, határok, SOP, megállási feltételek), a kód, a submit_results szerinti végeredmény, a Claude Code session-átiratok és a WORKLOG.md,
valamint egy rövid README.
